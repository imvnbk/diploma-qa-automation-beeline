# Ручные тест-кейсы: beeline.kz

**Объект тестирования:** сайт оператора Beeline Казахстан — https://beeline.kz
**Окружение:** Chrome (последняя версия), 1920x1080; дополнительно — мобильный вид 390x844
**Локали:** `/ru`, `/kk`

Приоритеты: **P1** — блокирующий/критичный путь, **P2** — важный, **P3** — второстепенный.
Колонка «Авто» показывает, покрыт ли кейс автотестом из этого репозитория.

## Подробные кейсы

### TC-01. Главная страница открывается
- **Предусловие:** браузер открыт, кеш очищен.
- **Шаги:**
  1. Открыть https://beeline.kz.
- **Ожидаемый результат:** страница загружается без ошибок, URL содержит `beeline.kz`, отображается контент главной страницы.

### TC-04 / TC-05. Переключение языка
- **Предусловие:** открыта страница `/ru` (для TC-04) или `/kk` (для TC-05).
- **Шаги:**
  1. Найти переключатель языка в шапке.
  2. Выбрать другой язык (`kk` или `ru`).
- **Ожидаемый результат:** URL меняется на целевую локаль (`/kk` или `/ru`), тексты страницы отображаются на выбранном языке.

### TC-06. Язык сохраняется при навигации
- **Предусловие:** открыта страница `/kk`.
- **Шаги:**
  1. Перейти в раздел «Тарифы» через меню.
  2. Перейти в раздел «Помощь».
- **Ожидаемый результат:** оба раздела открываются с локалью `/kk`, интерфейс остаётся на казахском.

### TC-07 / TC-08. Страница тарифов
- **Шаги:**
  1. Открыть `/ru/products/tariffs`.
  2. Найти заголовок «Тарифы для смартфона».
  3. Найти карточку первого тарифа в списке (название сверить с ответом `/api/tariff-list`).
- **Ожидаемый результат:** заголовок и карточка тарифа отображаются; в карточке видны название и цена.

### TC-09. Переход к описанию тарифа
- **Шаги:**
  1. Открыть `/ru/products/tariffs`.
  2. Нажать на карточку тарифа (кнопку «Подробнее» или название).
- **Ожидаемый результат:** открывается страница выбранного тарифа с его условиями.

### TC-10. Страница помощи
- **Шаги:**
  1. Открыть `/ru/help`.
- **Ожидаемый результат:** страница открывается, виден блок «Как мы можем помочь?».

### TC-11. Поиск по справке
- **Шаги:**
  1. Открыть `/ru/help`.
  2. Ввести в поиск запрос «интернет» и подтвердить.
- **Ожидаемый результат:** показан список релевантных статей; при запросе без совпадений — понятное сообщение «ничего не найдено», без ошибки.

### TC-12. Несуществующая страница
- **Шаги:**
  1. Открыть `https://beeline.kz/ru/this-page-does-not-exist`.
- **Ожидаемый результат:** отображается страница 404 с понятным текстом и ссылкой на главную; серверная ошибка (5xx) не показывается.

### TC-13. Мобильный вид
- **Предусловие:** DevTools → Device Toolbar, 390x844.
- **Шаги:**
  1. Открыть https://beeline.kz.
  2. Открыть меню-«бургер».
  3. Перейти в «Тарифы».
- **Ожидаемый результат:** нет горизонтальной прокрутки, элементы не перекрываются, меню открывается и закрывается, переход работает.

### TC-14. Кнопка «Личный кабинет»
- **Шаги:**
  1. Открыть https://beeline.kz/ru.
  2. Нажать на кнопку «Личный кабинет».
- **Ожидаемый результат:** отображается сообщение «Личный кабинет переехал в приложение «Janymda»» с текстом «В приложении можно смотреть детализацию, дарить ГБ, обменивать ГБ, получать приятные бонусы и многое другое», а также QR-код для перехода в приложение.

### TC-15. Поле поиска на странице помощи
- **Шаги:**
  1. Открыть `/ru/help`.
- **Ожидаемый результат:** отображается поле поиска с подсказкой «Что ищете?» и блок «Быстрые варианты:» с вариантами «узнать свой тариф», «подключить домашний интернет», «купить смартфон».

### TC-16. Меню навигации
- **Шаги:** открыть `/ru`, по очереди нажать «Тарифы и услуги», «Интернет дома + TV», «Помощь».
- **Ожидаемый результат:** открываются `/ru/products/tariffs`, `/ru/internet-home-tv-mobile`, `/ru/help`.

### TC-17. Плитки быстрых действий
- **Шаги:** открыть `/ru`, нажать плитки «Пополнить баланс», «Тарифы», «Замена SIM».
- **Ожидаемый результат:** открываются `/ru/top-up`, `/ru/products/tariffs`, `/ru/sim-restore`.

### TC-18. Контакты в подвале
- **Шаги:** открыть `/ru`, прокрутить страницу вниз.
- **Ожидаемый результат:** видны номера 116 и 3131 и почта infodesk@beeline.kz.

### TC-19–TC-24. Страница тарифов
- **Шаги:** открыть `/ru/products/tariffs`; проверить карточки тарифов (название, цена); нажать «Подробнее» и «Подключить» в первой карточке; перейти на вкладки «Для роутера» и «Услуги»; нажать «Архив тарифов»; раскрыть группу «Социальные тарифы».
- **Ожидаемый результат:** у каждой карточки видны название и цена; «Подробнее» открывает `/ru/products/tariffs/<slug>`; «Подключить» показывает окно с QR; вкладки открывают `/ru/products/tariffs/for-routers` и `/ru/products/services`; архив открывает `/ru/products/archived/tariffs`; группа «Социальные тарифы» раскрывается и показывает тарифы.

### TC-25. Вкладка «Для роутера»
- **Шаги:**
  1. Открыть `/ru/products/tariffs`.
  2. Нажать вкладку «Для роутера».
- **Ожидаемый результат:** открывается `/ru/products/tariffs/for-routers`, вкладка «Для роутера» выделена, отображается группа «Безлимитный интернет для роутера». В первой карточке видны название, цена и кнопки «Подробнее» и «Подключить».

### TC-26. Кнопки карточки тарифа для роутера
- **Шаги:**
  1. Открыть `/ru/products/tariffs/for-routers`.
  2. Нажать «Подробнее» в карточке тарифа.
  3. Вернуться назад и нажать «Подключить».
- **Ожидаемый результат:** «Подробнее» открывает страницу `/ru/products/tariffs/<slug>` этого тарифа; «Подключить» показывает окно подключения с QR-кодом.

### TC-27. Страница «Архив услуг»
- **Шаги:**
  1. Открыть `/ru/products/services/archive`.
  2. Просмотреть группы услуг.
- **Ожидаемый результат:** отображаются группы услуг (например, «Интернет пакеты», «Специальные услуги», «Дополнительные сервисы»); у каждой услуги видны название и стоимость, кнопка «Подробнее» открывает описание.

### TC-28. API: контент страницы услуг
- **Шаги:** отправить `POST /api/beeline-landings/query` с фильтрами `slug=archive`, `group=products`, `subGroup=services`, `locale=ru` и вложенным `populate` для `service_groups` → `services`.
- **Ожидаемый результат:** статус 200, JSON; в `data` одна страница с запрошенными slug/group/subGroup/locale; в ней есть группы услуг с названием и услугами; у каждой услуги заполнены название, slug, локаль `ru`, стиль `archive`, `costBlock`; slug услуг уникальны, цена (если указана) не отрицательна; у каждого перевода тот же slug и другая локаль.

### TC-29. API: несуществующая страница
- **Шаги:** отправить тот же запрос с несуществующим `slug`, `subGroup` или `group`.
- **Ожидаемый результат:** статус 200, `data` — пустой массив, ошибки нет.

### TC-30. API: некорректные запросы
- **Шаги:** отправить запрос с неизвестной локалью (`xx`); отправить запрос с некорректным JSON в теле (`{not a json`).
- **Ожидаемый результат:** сервер не отвечает ошибкой 5xx; для неизвестной локали, если статус 200, страницы в ответе нет.

### TC-31. Глобальный поиск
- **Шаги:**
  1. Открыть https://beeline.kz/ru/products/tariffs и вызвать поиск (иконка лупы в шапке).
  2. Ввести «телефон».
- **Ожидаемый результат:** отображаются результаты (услуги, тарифы, новости, акции); найденные фрагменты в заголовках и описаниях подсвечены; самые релевантные результаты вверху. Пустой запрос и запрос из случайных символов не приводят к ошибке страницы.
- **Проверка API:** `GET /api/global-search/search?q=телефон&limit=10&locale=ru` возвращает `200`, `data` с результатами, `meta.query`, `meta.total`, `meta.pagination.limit = 10`.
